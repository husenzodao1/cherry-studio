# Ҳамнаво

Барномаи оддии Android: телефони **А** садои худро (мусиқӣ аз ҳар барнома) тавассути
нуқтаи дастрасии Wi-Fi ба телефони **Б** мефиристад. Интернет, сервер ва пойгоҳи додаҳо лозим нест.

Талабот: Android 10 ё навтар дар ҳарду телефон.

## Насб

1. Дар GitHub ба **Releases** гузаред ва файли охирини `Hamnavo-1.0.N.apk`-ро дар телефон зеркашӣ кунед.
2. Файлро кушоед. Агар телефон пурсад, ба браузер иҷозати «насби барномаҳои номаълум» диҳед.
3. Барномаро дар ҳарду телефон насб кунед. Версияи нав болои кӯҳна насб мешавад (имзо якхела аст).

## Истифода

Дар як телефон танҳо як нақш кор мекунад: ё «Фиристодан», ё «Гирифтан».

**Телефони А (фиристанда)**

1. Нуқтаи дастрасии Wi-Fi (hotspot)-ро фаъол кунед (тугмаи «Танзимоти нуқтаи дастрасӣ»).
2. «Фиристодан»-ро пахш кунед, иҷозат диҳед ва «Оғоз»-ро интихоб кунед.
3. Мусиқиро дар ҳар барнома оғоз кунед.
4. «Садои санҷишӣ» се бип мефиристад; пахши дубора онро қатъ мекунад.

**Телефони Б (гиранда)**

1. Ба Wi-Fi-и телефони А пайваст шавед (ҳатто агар «бе интернет» нишон диҳад).
2. «Гирифтан»-ро пахш кунед. Барнома телефони А-ро худаш меёбад ва ҳангоми қатъ аз нав пайваст мешавад.
3. Агар наёбад, IP-и **телефони А**-ро (дар экрани телефони А навишта шудааст) дар майдони IP нависед.
   IP-и ҳамин телефонро нанависед.

Дар поёни экран рӯйхати ҳодисаҳо (пайвастшавӣ, хатоҳо) ҳаст — агар чизе кор накунад, аз он акс гиред.

**Ҳарду телефон:** «Иҷозати кор дар замина (батарея)»-ро як бор пахш кунед. Барои хотима «Қатъ»
ё тугмаи «Қатъ» дар огоҳинома.

## Эзоҳҳо

- Барнома садои худашро ҳеҷ гоҳ сабт намекунад, бинобар ин садо такрор намешавад.
- Баъзе барномаҳо сабти садои худро манъ мекунанд; садои онҳо фиристода намешавад.
- Таъхир худкор интихоб мешавад: дар Wi-Fi-и ором ~0.1 с, дар нуқтаи дастрасии ноустувор то ~0.8 с.
  Барнома суръати садоро ҳеҷ гоҳ иваз намекунад; агар Wi-Fi лаҳзае қатъ шавад, садо нарм хомӯш ва
  боз нарм фаъол мешавад (бе «фах-фах»), ва таъхир барои дафъаи дигар худаш зиёд мешавад.
- Дар экрани телефони Б «таъхир» ва «қатъшавӣ» (шумораи танаффусҳо) нишон дода мешаванд.
- Портҳо: TCP 47800 (садо), UDP 47801 (ҷустуҷӯ).

## Санҷишҳо

- `./gradlew testReleaseUnitTest` — санҷишҳои протокол, PCM, буфер, сервер/клиент, ҷустуҷӯ.
- CI (`.github/workflows/hamnavo.yml`) APK-и имзошударо дар ду эмулятори Android (API 29 ва 34) месанҷад:
  гирифтани садои барномаи дигар, сабт нашудани садои худ, се бип ва қатъи он, як нақш дар як телефон,
  ва фиристодани садо аз телефони А ба телефони Б. Релиз танҳо пас аз гузаштани ин санҷишҳо сохта мешавад.

Калиди имзо (`app/hamnavo-release.jks`) барои насби дастӣ дар репозиторий ҳаст. Барои калиди худ
сирҳои `HAMNAVO_KEYSTORE_BASE64`, `HAMNAVO_KEYSTORE_PASSWORD`, `HAMNAVO_KEY_ALIAS`, `HAMNAVO_KEY_PASSWORD`-ро гузоред.
